# Couple & Venue Images Directory

Place high-resolution wedding, engagement, or venue photographs in this folder:

1. `couple-cover.jpg` — (Optional) Pre-wedding photoshoot portrait for the front cover or welcome screen.
2. `college-days.jpg` — (Optional) Vintage college memory photo or illustration for Page 2 / 3.
3. `rambagh-palace.jpg` — (Optional) High-res backdrop of The Taj Rambagh Palace.
4. `og-preview.jpg` — 1200x630 image for WhatsApp and social media link previews.

To use custom images in the invitation, reference them from `/images/filename.jpg` inside `src/data/weddingData.js`.
